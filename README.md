# ASeven Pile — Website

Website **ASeven Pile** (jasa pondasi bore pile & strauss pile). Astro 5 static site, bahasa Indonesia, fokus local SEO (ratusan halaman kota).

## Perintah
```bash
npm install
npm run dev        # dev server, port 4321
npm run build      # build ke dist/
node scripts/linkcheck.mjs dist   # cek link internal rusak
```
